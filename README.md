# Hillhouse contamination reports — accessible copies

Accessible, downloadable copies of Wyre Council's official contamination reports for the **Hillhouse Technology Enterprise Zone, Thornton-Cleveleys**.

The council publishes several of these reports through **Issuu**, a third-party page-flipping platform that cannot be reliably downloaded and does not work well with screen readers and other assistive technology. **Hillhouse Watch** ([hillhousewatch.uk](https://hillhousewatch.uk)) has mirrored them here as ordinary, searchable PDF files so residents can actually open, read, print and keep them.

**Nothing in these documents has been altered.** They are the council's own reports. Where the original was a scanned image, a searchable text layer has been added by OCR so the document works with assistive technology; the content is unchanged. This repository exists partly as a permanent, timestamped public record: if a source document is later amended, re-redacted or removed, the git history here preserves what was published and when.
